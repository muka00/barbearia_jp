# Barbearia JP - MVP de Agendamento Online

> Aplicação web mobile-first desenvolvida em Flask para simplificar e automatizar o processo de agendamento de serviços em barbearias, com integração direta para envio de confirmações via WhatsApp.

---

## 📌 Sobre o Projeto

O **Barbearia JP** é um protótipo funcional (MVP) focado na experiência do usuário (UX) e acessibilidade (WCAG 2.1 AA). O sistema permite que clientes naveguem pelos serviços oferecidos, escolham profissionais e horários disponíveis e finalizem o agendamento de forma rápida e intuitiva em dispositivos móveis e desktops.

### 🎯 Funcionalidades Principais
* **Visualização de Serviços e Valores:** Apresentação clara de cortes, barba e pacotes com preços e tempos estimados.
* **Agendamento Interativo:** Seleção simples de barbeiro, data e horário.
* **Confirmação via WhatsApp:** Redirecionamento automático com mensagem formatada para confirmação direta com o estabelecimento.
* **Interface Responsiva & Acessível:** Layout mobile-first, botões com áreas de toque otimizadas (mínimo 44px) e alto contraste visual.

---

## 🛠️ Tecnologias Utilizadas
